# DBS-Group10-TheaterHelper
UWM CS557 Group 10 semester project. A webapp solution for an individual movie theater to keep track of movie/attendee data &amp; statistics.

IN PROGRESS GUIDE
Installation Guide(Run lines in terminal in chronological order)
Install Python: 
Activate Virtual Enviroment: .\.venv\Scripts\activate
Install Streamlit==1.43.0: pip install streamlit
Install numpy==1.26.4: pip install numpy
Install pandas==2.2.0: pip install pandas
Install plotly==5.18.0: pip install plotly
Install SQLAlchemy==2.0.49: pip install SQLAlchemy 
Install mysqlclient==2.2.8: pip install mysqlclient

Run App: python -m streamlit run app.py
